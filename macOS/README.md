# Dita Aí para macOS

## Ainda não existe instalador pronto para Mac

Diferente do Windows, aqui **não há um arquivo para baixar e executar**. É preciso compilar o app na sua máquina.

**O que isso exige:**

- Mac com chip Apple Silicon (M1 ou mais novo)
- Usar o Terminal
- Uns 15 minutos

### [→ Passo a passo da instalação](../README.md#o-que-você-precisa-macos)

Se você nunca abriu o Terminal, chame alguém que já abriu. Não é difícil, mas não é clicar em "avançar".

## Depois de instalado

Aperte **`Fn` + `Espaço`**, fale, solte. O texto aparece onde o cursor está.

O macOS vai pedir duas permissões na primeira vez — **Acessibilidade** e **Microfone**. Sem as duas o atalho não funciona.
