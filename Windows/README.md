# Dita Aí para Windows

## 1. Baixar

### **[→ CLIQUE AQUI PARA BAIXAR](https://github.com/felipefernandees/dita-ai/releases/latest)**

Na página que abrir, clique no arquivo que termina em **`.exe`**.

*(Se você baixou o projeto em ZIP, dê um duplo clique em **BAIXAR DITA AI.url** nesta mesma pasta.)*

## 2. Instalar

Execute o arquivo baixado.

**Vai aparecer uma tela azul: "O Windows protegeu o seu computador".**
Clique em **Mais informações** → **Executar assim mesmo**.

Isso é esperado. Acontece porque o instalador não tem certificado pago de assinatura, não porque haja algo errado com ele.

## 3. Primeiro uso

Na primeira vez que você ditar, o app baixa o modelo de voz — cerca de **1,6 GB**. Demora alguns minutos e acontece **uma vez só**. Depois disso funciona sem internet.

## 4. Como usar

Aperte **`Ctrl` + `Shift` + `Espaço`**, fale, aperte de novo.

O texto aparece no lugar onde o cursor está: WhatsApp Web, Word, e-mail, qualquer campo de texto.

Para trocar o atalho ou mudar o microfone: clique no ícone do Dita Aí ao lado do relógio → **Configurações**.
